# پروکسی اختیاری برای پخش در مرورگر

بیشتر لینک‌ها سالماند، ولی بعضی سرورها فقط به سایت خودشان اجازه دسترسی می‌دهند
(`Access-Control-Allow-Origin` ندارند یا فقط دامنه خودشان را مجاز می‌کنند).
مرورگر چنین جریانی را پخش نمی‌کند، هرچند VLC مشکلی ندارد.

این Worker کوچک، پلی‌لیست و قطعه‌ها را از سمت سرور می‌گیرد، آدرس‌های داخل
`.m3u8` را دوباره به سمت خودش می‌چرخاند و هدر CORS اضافه می‌کند. نتیجه این است
که همان لینک‌ها داخل داشبورد هم پخش می‌شوند.

این کار روی پلن رایگان Cloudflare Workers انجام می‌شود (روزانه ۱۰۰٬۰۰۰ درخواست).
برای تماشای شخصی کافی است؛ هر بیننده در هر ساعت چند هزار درخواست قطعه ایجاد می‌کند.

## راه‌اندازی در ۳ دقیقه (بدون نصب چیزی)

1. وارد <https://dash.cloudflare.com/> شوید و از منوی **Workers & Pages** گزینه
   **Create** → **Worker** را بزنید.
2. یک نام مثل `iptv-proxy` بدهید و **Deploy** کنید.
3. روی **Edit code** بزنید، تمام محتوای `worker/worker.js` را جای‌گذاری کنید و
   دوباره **Deploy** کنید.
4. آدرسی مثل `https://iptv-proxy.<account>.workers.dev` می‌گیرید.
5. در داشبورد IPTV، بخش «پخش شبکه‌هایی که مرورگر مسدود می‌کند» را باز کنید،
   آدرس Worker را وارد و **ذخیره** کنید.

از این به بعد دکمه «پخش» همه لینک‌ها را از پروکسی رد می‌کند. آدرس فقط در
`localStorage` همان مرورگر ذخیره می‌شود و در ریپو نوشته نمی‌شود.

## امنیت

Worker به‌صورت پیش‌فرض یک پروکسی باز است؛ هر کسی که آدرسش را بداند می‌تواند
از آن استفاده کند. برای بستنش، در ابتدای فایل مقدار `TOKEN` را عوض کنید:

```js
const TOKEN = "یک-رشته-تصادفی-طولانی";
```

بعد آدرس را این‌طور در داشبورد وارد کنید:

```
https://iptv-proxy.<account>.workers.dev/?token=یک-رشته-تصادفی-طولانی
```

داشبورد خودش `&url=...` را به همین آدرس اضافه می‌کند. توکن را در ریپو یا
جای عمومی نگذارید.

## محدودیت‌ها

- اگر سرور مبدأ IP خارجی را بلاک کند (محدودیت جغرافیایی)، پروکسی هم کمکی
  نمی‌کند. Cloudflare در ایران PoP ندارد و درخواست از نزدیک‌ترین دیتاسنتر
  (مثلاً امارات/ترکیه) خارج می‌شود.
- بعضی سرورها به `Referer` خاصی نیاز دارند؛ این Worker فقط User-Agent و Range
  را رد می‌کند. اگر شبکه‌ای پخش نشد، با VLC امتحان کنید.
- پخش زنده از پروکسی، ترافیک بیشتری مصرف می‌کند. برای استفاده مداوم، پلن
  رایگان Cloudflare کافی است ولی مصرف را در داشبورد Workers ببینید.

## تست سریع

بعد از Deploy، این آدرس باید یک پلی‌لیست برگرداند که همه URIهایش با آدرس
Worker شروع می‌شوند:

```
https://iptv-proxy.<account>.workers.dev/?url=https%3A%2F%2Fncdn.telewebion.ir%2Ftv1%2Flive%2Fplaylist.m3u8
```
